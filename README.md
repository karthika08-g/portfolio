# Personal Portfolio Website

A simple and responsive personal portfolio website created using **HTML and basic CSS**. This project showcases my personal information, skills, interests, and contact details through a clean and beginner-friendly design.

## Pages

* **Home** – Introduces me and provides basic information about my profile.
* **Contact** – Provides contact details and a way to connect with me.

## Technologies Used

* HTML5
* CSS3

## Features

* Clean and simple design
* Responsive layout
* Easy navigation between pages
* Beginner-friendly HTML and CSS structure
* Separate Home and Contact pages

## Purpose

I created this project to practice my **HTML and CSS fundamentals** and to build my first personal portfolio website as a CSE student interested in **Full-Stack Development**.
